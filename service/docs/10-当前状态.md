## 7. 5 分钟自检

```bash
# 0) 先起服务（Git Bash）
cd /d/deepseek/astock_sectors/service && ./start.sh

# 1) 服务与水位线
curl -s http://127.0.0.1:3999/api/health; echo
curl -s http://127.0.0.1:3999/api/data/version; echo

# 2) 页面
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:3999/

# 3) 抽样行业
curl -s http://127.0.0.1:3999/api/industries/801770 | python -m json.tool | head -40

# 4) 同步审计（不应有 running）
curl -s 'http://127.0.0.1:3999/api/sync/logs?limit=5' | python -m json.tool

# 5) 文档一致性
python D:\deepseek\astock_sectors\service\docs\_check_docs.py
```

判据：1) `status=ok` 且 `lastTradeDate` = 应到交易日（上游故障时允许落后，但 `syncing` 必须 false）；4) 无 `running`；5) 「全部通过」。
