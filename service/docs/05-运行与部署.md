# 05 · 运行与部署

## 1. 环境要求

| 项 | 版本 | 说明 |
|---|---|---|
| 操作系统 | Windows 10/11（已在 Win10 19045 验证） | 也可以跑 Linux/macOS，路径与脚本需微调 |
| Python | 3.11+（本机 3.13.2） | 依赖已 vendor，无需联网安装 |
| Node.js | 18+（本机 26.13.1） | 仅构建前端时需要；日常运行不需要 |
| npm | 9+（本机 11.20.0） | 同上 |
| 浏览器 | Chrome / Edge | ECharts 需要现代浏览器 |
| 磁盘 | 约 200 MB（依赖 + node_modules） | 数据文件 < 1 MB |

## 2. 首次启动

```powershell
cd D:\deepseek\astock_sectors\service
.\start.cmd
```

> 为什么用 `.cmd`：Windows 默认执行策略禁止运行 `.ps1`。`start.cmd` 内部以
> `powershell -ExecutionPolicy Bypass -File start.ps1` 调用，无需修改系统策略。
> PowerShell 7 环境也可直接 `.\start.ps1`。

脚本做的事：

1. 探测 `http://127.0.0.1:3999/api/health`：已运行则直接打开浏览器并退出（不会重复启动）。
2. 检查 `frontend/dist/index.html`，不存在则 `npm install && npm run build`（首次约 1~2 分钟）。
3. 检查 3999 端口是否被其他程序占用，占用则报错退出。
4. 以隐藏窗口启动 `python run.py`。
5. 轮询 `/api/health`，就绪后自动打开浏览器。
6. 前台等待进程退出（Ctrl+C 或关闭窗口即停止）。

启动后：

- 页面：<http://127.0.0.1:3999>
- API 文档：<http://127.0.0.1:3999/docs>
- 健康检查：<http://127.0.0.1:3999/api/health>

## 3. 日常命令

| 目的 | 命令 |
|---|---|
| 启动（推荐） | `.\start.cmd` |
| 仅后端（前台，看日志） | `cd backend; python run.py` |
| 后端热重载（开发） | `cd backend; python run.py --reload` |
| 前端热更新（开发） | `cd frontend; npm run dev`（<http://127.0.0.1:5173>） |
| 重新构建前端 | `cd frontend; npm run build` |
| 初始化/重置数据 | `cd backend; $env:PYTHONPATH=".;.\vendor;..\..\vendor"; python -m app.seed` |
| 清理缓存（可重复执行） | `..\clean.cmd`（预览：`..\clean.cmd -DryRun`） |
| 停止服务 | 关闭启动窗口；或 `Get-NetTCPConnection -LocalPort 3999 -State Listen | % { Stop-Process -Id $_.OwningProcess }` |
| 查看端口占用 | `Get-NetTCPConnection -LocalPort 3999` |

> `python -m app.seed` 必须在 `backend` 目录下执行，且 `PYTHONPATH` 要包含 `vendor` 与上一级的 `vendor`（baostock 在那里）。

## 4. 环境变量

复制 `.env.example` 为 `.env` 后修改即可生效（`config.py` 启动时自动加载，且**不覆盖**已存在的进程环境变量）。
配置优先级：**进程环境变量 > `service/.env` > 代码默认值**。

| 变量 | 默认值 | 说明 |
|---|---|---|
| `ASTOCK_HOST` | `127.0.0.1` | 监听地址；不要改成 `0.0.0.0` 对外暴露 |
| `ASTOCK_PORT` | `3999` | 服务端口 |
| `ASTOCK_DATABASE_URL` | `sqlite:///.../data/astock.db` | 阶段二换成 `mysql+pymysql://...` |
| `ASTOCK_DATA_DIR` | `service/data` | SQLite 文件目录 |
| `ASTOCK_BASE_MONTH` | `2023-12` | 归一化基期 |
| `ASTOCK_SEED_FROM` | `2023-12-01` | 全量同步起点 |
| `ASTOCK_HISTORY_START` | `2024-01` | 查询默认起始月份 |
| `ASTOCK_ADMIN_TOKEN` | `local-dev-token` | 维护接口令牌 |
| `ASTOCK_CORS_ORIGINS` | `http://127.0.0.1:5173,http://localhost:5173` | 开发态跨域白名单 |

## 5. 目录与关键文件

| 路径 | 作用 | 是否可删 |
|---|---|---|
| `backend/app/` | 后端源码 | 否 |
| `backend/vendor/` | Python 依赖 | 否（删了要重装） |
| `backend/run.py` | 启动入口（注入 vendor 路径） | 否 |
| `frontend/src/` | 前端源码 | 否 |
| `frontend/dist/` | 构建产物 | 可删，删后需重新 build |
| `frontend/node_modules/` | 前端依赖 | 可删，重装需联网 |
| `data/astock.db` | 数据库 | 可删，删后 seed 重建 |
| `data/astock.db-wal` / `-shm` | SQLite WAL 文件 | 随主库 |
| `docs/` | 文档 | 否 |

## 6. 日志

- 服务日志：`python run.py` 的标准输出（`start.ps1` 隐藏了窗口，日志不落盘）。
- 需要日志文件时，改为前台启动并重定向：

```powershell
cd backend
python run.py *>> ..\data\service.log
```

- 同步日志：数据库 `sync_log` 表 + `GET /api/sync/logs`。
- 业务异常不会写文件，只在响应里返回 `detail`。

## 7. 备份与恢复

SQLite 是单文件，备份 = 复制文件（先停服务，避免 WAL 未合并）：

```powershell
Stop-Process -Id (Get-NetTCPConnection -LocalPort 3999 -State Listen).OwningProcess
Copy-Item .\data\astock.db .\data\backup\astock-20261115.db
```

恢复：停服务 → 覆盖 `astock.db` → 启动。

> 不要只复制 `astock.db` 而漏掉 `-wal`：若服务在运行中复制，可能拿到不一致快照。

## 9. 开机自启（可选）

把 `start.ps1` 的快捷方式放入：

```
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup
```

或注册计划任务（登录时触发，运行 `powershell -WindowStyle Hidden -File ...\start.ps1`）。
注意：`start.ps1` 会在服务退出后结束，计划任务里建议改用 `python run.py` 直接跑。

## 10. 故障排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| `端口 3999 已被占用` | 上一次服务没退干净 | `Get-NetTCPConnection -LocalPort 3999` 找 PID 后 `Stop-Process`，或改 `ASTOCK_PORT` |
| 页面 404 / 空白 | `frontend/dist` 不存在或构建失败 | `cd frontend; npm run build`；看构建报错 |
| 页面提示「前端尚未构建」 | 后端启动时 dist 不存在 | 同上，构建后重启后端 |
| `ModuleNotFoundError: fastapi` | 没用 `run.py` 启动，或 vendor 被删 | 用 `python run.py`；或重跑 `vendor_backend2.py` |
| 同步一直 `running` | baostock 网络慢/断连 | 看 `sync_log.message`；等 3 次重试结束；再手动点一次 |
| 同步 `failed`，提示 baostock | 上游登录失败 | 重试；检查网络能否访问 baostock |
| 页面数据不更新 | 非交易日 / 未到 15:05 | 正常；`/api/data/version` 看 `needsRefresh` |
| 某只股票图表断线 | 停牌或缺月 | `/api/admin/quality` 查 `missing_month`；补数据或接受断点 |
| 中文乱码（终端） | PowerShell 编码 | 接口本身是 UTF-8；`$OutputEncoding=[Text.UTF8Encoding]::new($false)` 或看浏览器 |
| `npm` 报 `spawn EPERM` | 沙箱/权限限制 | 在普通终端运行；本机已在普通终端验证通过 |
| 提示「禁止运行脚本」 | Windows 执行策略为 Restricted | 用 `.\start.cmd`，或 `powershell -ExecutionPolicy Bypass -File .\start.ps1` |
| `start.cmd` 闪退 | 端口冲突/依赖缺失 | 在 cmd 窗口里运行 `service\start.cmd` 查看输出；或按提示前台 `python run.py` |
