# 04 · 接口文档

## 1. 通用约定

| 项 | 约定 |
|---|---|
| Base URL | `http://127.0.0.1:3999` |
| 数据格式 | JSON（UTF-8，中文不转义）；CSV 接口带 BOM 头，Excel 直接打开不乱码 |
| 时间 | 日期 `YYYY-MM-DD`，月份 `YYYY-MM`，时间戳 `YYYY-MM-DD HH:MM:SS`（Asia/Shanghai） |
| 金额单位 | 价格 = 元（前复权）；市值 = 亿元；涨跌幅 = 百分数（`-8.49` 表示 -8.49%） |
| 错误格式 | `{"detail": "错误说明"}`，HTTP 400/401/404/422/500 |
| 鉴权 | 仅 `/api/admin/*` 需要请求头 `X-Admin-Token`，默认值 `local-dev-token` |
| 交互文档 | <http://127.0.0.1:3999/docs>（Swagger UI）、`/redoc`、`/openapi.json` |

**状态码**

| 码 | 含义 |
|---|---|
| 200 | 成功 |
| 400 | 参数错误（如 `codes` 为空、超过 60 只、无可更新字段） |
| 401 | 维护接口 token 错误 |
| 404 | 行业/股票/任务不存在 |
| 422 | FastAPI 参数校验失败（如 `trigger` 不在枚举内） |

## 2. 基础

### 2.1 `GET /api/health`

存活与数据概况。

```json
{"status": "ok", "rows": 5616, "lastTradeDate": "2026-11-13", "baseMonth": "2023-12"}
```

### 2.2 `GET /api/data/version`

水位线与刷新判定，前端刷新时第一个调用的接口。

```json
{
  "lastTradeDate": "2026-11-13",
  "expectedTradeDate": "2026-11-13",
  "lastSyncAt": "2026-11-15 22:13:58",
  "needsRefresh": false,
  "syncing": false,
  "rows": 5616
}
```

| 字段 | 说明 |
|---|---|
| `expectedTradeDate` | 最近一个「应当已有收盘数据」的交易日：工作日 15:05 后取当天，否则取上一个工作日 |
| `needsRefresh` | `lastTradeDate < expectedTradeDate` 或库为空时为 `true` |
| `syncing` | 后台是否有同步任务在跑 |

### 2.3 `GET /api`

服务自描述（便于探活）。

```json
{"service": "astock", "docs": "/docs", "port": 3999}
```

### 3.1 `GET /api/industries`

31 个行业 + 各自前五（按 rank 升序）。

```json
[
  {
    "code": "801010",
    "name": "农林牧渔",
    "stock_count": 103,
    "sort_order": 0,
    "leaders": [
      {"code": "002714", "name": "牧原股份", "weight": 18.6415, "rank": 1},
      {"code": "300498", "name": "温氏股份", "weight": 16.3064, "rank": 2},
      {"code": "002311", "name": "海大集团", "weight": 6.218, "rank": 3},
      {"code": "002157", "name": "正邦科技", "weight": 3.7045, "rank": 4},
      {"code": "000876", "name": "新希望", "weight": 2.3872, "rank": 5}
    ]
  }
]
```

### 3.2 `GET /api/industries/{code}`

单行业详情：5 只龙头的月度序列 + 指标 + 沪深300 基准。

**路径参数**：`code` — 6 位行业代码，如 `801770`（通信）。

```json
{
  "code": "801770",
  "name": "通信",
  "stockCount": 122,
  "leaders": [
    {
      "code": "300308", "name": "中际旭创", "industry_code": "801770",
      "weight": 20.15, "rank": 1, "mktcap": 5491.41, "is_leader": true,
      "series": [
        {"month": "2023-12", "trade_date": "2023-12-29", "close": 80.284, "ret": null, "norm": 100.0},
        {"month": "2024-01", "trade_date": "2024-01-31", "close": 73.096, "ret": -8.95, "norm": 91.05}
      ],
      "metrics": {
        "base_close": 80.284, "last_close": 466.2, "last_month": "2026-11", "months": 35,
        "cum_return": 480.69, "cagr": 82.8, "mdd": -63.2, "annual_vol": 87.0,
        "best": {"month": "2025-08", "ret": 63.1},
        "worst": {"month": "2026-10", "ret": -31.5}
      }
    }
  ],
  "benchmark": {"name": "沪深300", "metrics": {"cum_return": 17.06}, "series": []},
  "avgCumReturn": 288.84,
  "baseMonth": "2023-12"
}
```

> `series` 从基期 `2023-12` 开始（用于计算归一化），`metrics.months` 只统计 `2024-01` 之后的月份。
> `benchmark.series` 结构同 `leaders[].series`，文档示例中省略。

**错误**：`404 {"detail": "行业不存在"}`

## 5. 价格序列

### 5.1 `GET /api/prices`

任意股票组合的月度序列（最多 60 只）。

| 参数 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `codes` | 是 | — | 逗号分隔，如 `300308,300502,000300`；`000300` 为基准 |
| `start` | 否 | `2024-01` | 起始月份 `YYYY-MM` |
| `end` | 否 | 最新 | 结束月份 `YYYY-MM` |
| `normalize` | 否 | `true` | 预留参数，当前响应同时返回 `close` 与 `norm` |

```json
{
  "months": ["2024-01", "2024-02"],
  "series": [
    {
      "code": "300308", "name": "中际旭创", "isBenchmark": false, "weight": 20.15,
      "metrics": {"cum_return": 480.69, "mdd": -63.2, "annual_vol": 87.0},
      "series": [
        {"month": "2024-01", "close": 73.096, "ret": -8.95, "norm": 91.05},
        {"month": "2024-02", "close": 110.326, "ret": 50.93, "norm": 137.42}
      ]
    }
  ],
  "normalize": true,
  "baseMonth": "2023-12"
}
```

**错误**

- `400 {"detail": "codes 不能为空"}`
- `400 {"detail": "一次最多查询 60 只"}`

### 5.2 `GET /api/export.csv`

导出当前组合的月度数据（UTF-8 BOM，Excel 可直接打开）。

| 参数 | 必填 | 说明 |
|---|---|---|
| `codes` | 是 | 同 `/api/prices` |
| `start` | 否 | 默认 `2024-01` |

列：`行业, 代码, 名称, 月份, 月末收盘, 月涨跌%, 归一化`

```powershell
Invoke-WebRequest 'http://127.0.0.1:3999/api/export.csv?codes=300308,300502' -OutFile prices.csv
```

## 6. 同步

### 6.1 `POST /api/sync`

触发增量同步。**立即返回**，不等待抓取完成。

| 参数 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `trigger` | 否 | `page` | `page` / `manual` / `seed` |

```json
{"jobId": "6ea9762b5be1", "status": "running", "reused": false}
```

- `reused: true` 表示已有任务在跑，直接复用它（单飞）。
- 同一时刻只会有一个同步任务。

### 6.2 `GET /api/sync/{job_id}`

查询任务进度（路径参数名 `job_id`，前端传入 `jobId`）。

```json
{
  "jobId": "6ea9762b5be1",
  "status": "running",
  "trigger": "manual",
  "startedAt": "2026-11-15 22:13:23",
  "addedRows": 0,
  "rebuilt": 0,
  "done": 87,
  "total": 156,
  "message": "",
  "reused": false
}
```

| `status` | 含义 |
|---|---|
| `running` | 进行中，看 `done/total` |
| `done` | 完成，看 `addedRows` / `rebuilt` / `latestDate` / `durationMs` |
| `failed` | 失败，看 `error`（已写 `sync_log`） |

**错误**：`404 {"detail": "任务不存在"}`（服务重启后内存任务会丢失）

### 6.3 `GET /api/sync/logs?limit=20`

同步历史（按 id 倒序）。

```json
[
  {
    "id": 1,
    "started_at": "2026-11-15 22:13:23",
    "finished_at": "2026-11-15 22:13:58",
    "trigger": "manual",
    "window_start": "2026-11-03",
    "window_end": "2026-11-15",
    "added_rows": 0,
    "rebuilt": 0,
    "status": "ok",
    "message": "耗时 35.3s"
  }
]
```

`limit`：1~200，默认 20。

## 7. 维护（需鉴权）

请求头：`X-Admin-Token: local-dev-token`（生产请在 `.env` 改掉）。

### 7.1 `GET /api/admin/quality`

数据体检：缺月、行业悬挂。

```powershell
Invoke-RestMethod 'http://127.0.0.1:3999/api/admin/quality' -Headers @{'X-Admin-Token'='local-dev-token'}
```

```json
{"checked": 155, "issues": [], "total": 0}
```

```json
{
  "checked": 155,
  "issues": [{"code": "002157", "name": "正邦科技", "type": "missing_month", "detail": "2024-03,2024-04"}],
  "total": 1
}
```

### 7.2 `PUT /api/admin/stocks/{code}`

维护单只股票的名称/权重/排名/是否龙头/市值。

**请求体**（至少一个字段）：`name` / `weight` / `rank` / `is_leader` / `mktcap`

```powershell
Invoke-RestMethod 'http://127.0.0.1:3999/api/admin/stocks/300308' `
  -Method Put -ContentType 'application/json' `
  -Headers @{'X-Admin-Token'='local-dev-token'} `
  -Body '{"weight": 21.5, "rank": 1}'
```

```json
{"ok": true, "stock": {"code": "300308", "name": "中际旭创", "industry_code": "801770", "weight": 21.5, "rank": 1, "mktcap": 5491.41, "is_leader": true, "updated_at": "2026-11-15 22:40:00"}}
```

**错误**

- `401 {"detail": "X-Admin-Token 无效"}`
- `404 {"detail": "股票不存在"}`
- `400 {"detail": "没有可更新字段"}`

> 注意：当前修改 `weight/rank` **不会**自动重排同行业其他股票的名次，需要逐只调整。

## 8. 前端静态资源

| 路径 | 说明 |
|---|---|
| `GET /` | 返回 `frontend/dist/index.html` |
| `GET /assets/*` | 构建产物（JS/CSS） |
| `GET /{path}` | SPA 回退：非 `api/` 前缀且文件不存在时返回 `index.html` |

## 9. 调用示例（完整流程）

```powershell
# 1) 看数据是否最新
$v = Invoke-RestMethod 'http://127.0.0.1:3999/api/data/version'
if ($v.needsRefresh) {
  # 2) 触发同步并轮询
  $job = Invoke-RestMethod 'http://127.0.0.1:3999/api/sync' -Method Post
  do {
    Start-Sleep -Seconds 2
    $st = Invoke-RestMethod "http://127.0.0.1:3999/api/sync/$($job.jobId)"
    Write-Host "$($st.status) $($st.done)/$($st.total)"
  } while ($st.status -eq 'running')
}

# 3) 查通信行业前五
$d = Invoke-RestMethod 'http://127.0.0.1:3999/api/industries/801770'
$d.leaders | Select-Object name, weight, @{n='区间涨跌';e={$_.metrics.cum_return}}

# 4) 导出
Invoke-WebRequest "http://127.0.0.1:3999/api/export.csv?codes=$($d.leaders.code -join ',')" -OutFile tongxin.csv
```

## 10. 版本与兼容性

- 当前 API 版本 v1（路径未带版本号）。
- 新增字段视为向后兼容；**删除/改名**视为破坏性变更，需同步改前端 `types.ts` 并记录到 [09-变更日志.md](09-变更日志.md)。
- 无分页/无限流；`/api/prices` 的 60 只上限是唯一的保护。
