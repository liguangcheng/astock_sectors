## 2026-11-20 · 运维脚本 bash 化（不升版本）

只换脚本，不动业务代码、接口、表结构与数据。

### 变更

- **删除 PowerShell**：`service/start.ps1`、`service/start.cmd`、`clean.ps1`、`clean.cmd`（历史见 git）。
- **新增 `service/start.sh`**（等价原 `start.ps1`）：
  - 已在运行 → 开浏览器退出 0；缺 `frontend/dist` → `npm install && npm run build`；
  - 端口被占用 → 列出 PID 并退出 1；
  - 后台启动 `python run.py`，日志落 `service/data/service.log`；
  - 就绪轮询 20s → 90s（冷启动首次 import pandas/baostock 可能十几秒，实测 4~20s）；
  - `Ctrl+C` 连带停掉后端（原 PS 版是隐藏子进程，可能残留，靠 `stop.sh` 兜底）。
- **新增 `service/stop.sh`**（原方案靠手敲 `Stop-Process`）：按端口找监听进程，
  Windows `taskkill /T /F`，Linux/mac 先 TERM 再 KILL；支持 `--dry-run`、`--force`、`--timeout`、`--port`，可重复执行。
- **新增根目录 `clean.sh`**（等价原 `clean.ps1`）：`--dry-run` 预览，只删缓存，不动 data/依赖/交付物。
- **新增 `.gitattributes`**：`*.sh text eol=lf`，防止 `core.autocrlf=true` 把脚本检出成 CRLF。
- `.gitignore` 增加 `*.pid`；启动/停止都认 `ASTOCK_PORT` 与 `service/.env`，并支持 `--port`。

### 验证（Git Bash，2026-11-20）

- 启动、重复启动（不误杀）、停止、幂等停止、TERM 收尾、端口占用、换目录启动：**27 项全过**。
- `clean.sh` dry-run/实际执行、`stop.sh --force`、`ASTOCK_PORT=4123`、缺 dist 自动构建（npm 桩）：**23 项全过**。
- 启动后 `/api/health` 与首页均 200；停止后 3999 释放、无残留进程。

## v0.2.0 — 2026-11-15 · 本地服务化

首个可运行版本：查询 API + 图表页面 + 增量同步。

### 新增

- **后端**（`service/backend`）
  - FastAPI 应用，`127.0.0.1:3999`，`/docs` 可用
  - 12 个 REST 接口（健康、水位线、行业、详情、总览、价格、导出、同步×3、维护×2）
  - SQLAlchemy Core 表结构 5 张：`industry` / `stock` / `price_daily` / `sync_state` / `sync_log`
  - 仓储层 `repo.py`：SQLite / MySQL 双方言 upsert
  - 分析层 `analytics.py`：月末聚合、区间收益、年化、最大回撤、年化波动、归一化
  - 同步服务 `sync_service.py`：水位线 + 单飞锁 + 异步 job + 复权重叠校验 + 失败重试
  - 种子导入 `seed.py`：从上一阶段 JSON 导入 31 行业 / 155 龙头 / 5,616 行
- **前端**（`service/frontend`）
  - React 18 + TypeScript + Vite + ECharts
  - 总览页：4 个 KPI、31 行业柱状图（含沪深 300 参考线）、31 张可点击行业卡
  - 行业详情页：5 条月度折线、绝对价格/归一化切换、沪深 300 叠加、11 列指标表
  - 顶栏：数据截至日期、上次同步时间、手动同步按钮、同步进度提示
  - 页面刷新自动检测新交易日并增量同步（每会话仅自动触发一次）
- **工程**
  - `start.ps1` 一键启动（缺产物自动构建、端口检查、自动开浏览器）
  - `backend/vendor` + `vendor_backend2.py`（清华镜像迷你 pip，离线可用）
  - `config.py` 支持 `service/.env` 自动加载（进程环境变量优先）
  - `docker-compose.mysql.yml`（mysql:8.4，映射 3307）
  - 文档：`docs/00`~`09` 共 11 篇 + 根目录 `AGENTS.md` + 自检脚本 `docs/_check_docs.py`

### 变更

- 行情数据源统一为 **baostock**（前期曾用腾讯，因前复权口径差异改为单一源，见 ADR-009）。
- 数据截断日固定为 `2026-11-13`，避免种子数据写入「未来日期」污染水位线。

### 修复

- 种子导入时把 2026-11 月末写成 11-30（未来日期），导致同步认为数据已最新 —— 已用 `SEED_CUTOFF` 夹紧到 11-13。
- `/api/prices` 中基准序列在「绝对价格」模式下量级过大压扁个股曲线 —— 前端改为仅在归一化模式叠加基准。

### 已知问题

- P5 维护页未做（后端接口已有）。
- P6 MySQL 未实际切换（compose 与代码就绪）。
- 无自动化测试。
- 同步任务状态在内存，重启丢失。
- `/api/prices` 的 `normalize` 参数当前无实际作用。
