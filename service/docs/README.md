## 维护约定

- **状态类**（10）：每次发布、每次数据事件后更新；行数与日期以 `/api/health` 实测为准。
- **计划类**（11）：每个版本开始/结束时勾选；调整优先级要留变更记录。
- 代码改动若影响 **接口、表结构、环境变量、启动方式**，必须同步更新对应文档，并在 [09-变更日志.md](09-变更日志.md) 追加一条。
- 文档中的数字（行数、条数、版本号）以 [10-当前状态.md](10-当前状态.md) 为准；静态口径以 [00-项目记忆.md](00-项目记忆.md) 为准。
- 修改文档后跑一次自检脚本（检查链接、接口清单、环境变量是否漏写）：

```powershell
python D:\deepseek\astock_sectors\service\docs\_check_docs.py
```
