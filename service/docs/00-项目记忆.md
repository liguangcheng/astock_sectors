# 00 · 项目记忆（长期记忆）

> 这份文档是项目的「背景知识压缩包」。新接手的工程师或 AI 会话，读完这一篇就能理解：

## 1. 一句话描述

把「31 个申万一级行业 × 每行业权重前五龙头 × 2024 年以来月度股价」做成一个**本地前后端分离服务**：
后端 FastAPI 提供查询与增量同步 API，前端 React + ECharts 展示折线图，数据先落 SQLite，后期可切 MySQL。

- 访问地址：`http://127.0.0.1:3999`
- 代码位置：`D:\deepseek\astock_sectors\service`
- 数据来源：申万宏源研究所（行业分类与权重）+ baostock（前复权日线）

---

## 2. 业务背景（为什么是申万、为什么是权重前五）

1. **A 股行业分类有多套**：证监会行业、中信行业、申万行业、Wind 行业，以及各种「概念板块」。
   本项目选 **申万行业分类（2021 版）**，因为它是券商研报与 A 股行业比较的事实标准，且申万官网公开每个行业指数的**成分股与权重**。
2. **「龙头」不能拍脑袋**：本项目把「龙头」定义为**该行业在申万行业指数中权重最高的 5 只股票**。
   权重由市值与自由流通市值决定，比「市值最大」「涨幅最高」更接近机构视角，而且**可复现、可核对**。
3. **只有 31 个一级行业**：申万一级行业共 31 个（2021 版），覆盖全部 A 股；二级/三级更细，本项目不展开。
4. **为什么是 155 只**：31 × 5 = 155。每行业固定前五，便于横向比较，也避免行业大小导致的样本不均。

## 3. 数据口径（改代码前必须对齐）

| 项 | 口径 |
|---|---|
| 行业 | 申万一级 31 个，代码如 `801080`（电子） |
| 成分股与权重 | 申万宏源研究所官网接口，最新一期发布值，单行业权重合计约 100% |
| 龙头 | 每个行业按权重降序取前 5；剔除 2024 年后上市、月度数据不足 30 个月的次新股（如长鑫科技、华电新能） |
| 价格 | **前复权**日线，取每月最后一个交易日收盘价；2026-11 为截至 11-13 的月内数据 |
| 区间 | 基期 `2023-12` 月末；展示区间 `2024-01` ~ 最新月 |
| 归一化 | `收盘 / 基期收盘 × 100`，基期 = 100 |
| 区间累计涨跌 | `最新收盘 / 基期收盘 − 1` |
| 年化收益 | `(最新/基期)^(12/月数) − 1` |
| 最大回撤 | 月末收盘序列自历史峰值的最大跌幅 |
| 年化波动率 | 月度收益率标准差 × √12 |
| 基准 | 沪深 300（代码 `000300`，指数不复权） |
| 时区 | 全链路 `Asia/Shanghai`；「今天已收盘」判定为 15:05 之后 |

**核对数字（2026-11-15 数据快照）**：

- 155 只龙头中 **114 只上涨**，中位数 `+29.2%`，均值 `+59.3%`
- 沪深 300 同期 `+17.06%`
- 最强：电子（寒武纪 `+981.6%`）、国防军工（松发股份 `+892.7%`）、通信（新易盛 `+650.4%`）
- 最弱：美容护理（前五均值 `-39.0%`）、社会服务（`-25.0%`）、食品饮料（`-12.3%`）

> 这些数字与上一阶段报告《A股31个申万一级行业龙头股月度股价走势研究》一致，可用于回归校验。

## 4. 术语表

| 术语 | 含义 |
|---|---|
| 申万一级行业 | 申万行业分类的第一层，31 个，代码 `801xxx` |
| 权重 | 该股票在申万行业指数中的市值权重（%），本项目用作「龙头」排序依据 |
| 龙头 | 本项目特指「权重前五」，rank=1 为权重第一 |
| 前复权（qfq） | 以最新价格为基准向前调整历史价格，消除分红送转造成的价格跳空 |
| 后复权（hfq） | 以上市首日为基准向后调整，价格会越走越高 |
| 不复权 | 原始成交价，分红除权日会出现缺口 |
| 归一化 | 以基期收盘为 100 重新标度，用于不同价位股票横向比较 |
| 单飞（single-flight） | 同一时刻只允许一个同步任务，后来的请求复用进行中的任务 |
| 水位线（watermark） | 已入库的最新交易日，决定增量抓取窗口的起点 |

## 5. 数据源与外部依赖

| 用途 | 来源 | 说明 |
|---|---|---|
| 行业列表、成分股、权重 | `https://www.swsresearch.com/institute-sw/api/index_publish/details/component_stocks/` | 公开接口，无需鉴权；参数 `swindexcode`、`page`、`page_size`；2026-11 实测可用 |
| 日线行情 | `baostock`（Python 包，socket 协议） | `query_history_k_data_plus(..., adjustflag="2")` 前复权；指数用 `adjustflag="3"` |
| 备选行情源 | 腾讯 `proxy.finance.qq.com/ifzqgtimg/appstock/app/newfqkline/get` | 稳定但**前复权口径与 baostock 略有差异**（分红处理不同，个股区间收益可差 1~13 个百分点），仅作交叉校验，不作为本服务数据源 |
| 备选行情源 | 新浪 `money.finance.sina.com.cn/.../getKLineData` | 前复权口径与 baostock 差异较大（实测可达 187 个百分点），不可混用 |

**结论：行情只用 baostock，且一次定源。** 混用不同源的前复权价会产生「同一月份两个价格」的脏数据。

## 6. 已知的坑（血泪清单）

1. **前复权会漂移**：每次分红送转，整段历史前复权价都会被重算。
   → 本服务在同步时比对「同月份重叠收盘价」，偏差 > 0.5% 判定复权因子变化，重抓该股全历史并整体替换（`sync_log.rebuilt`）。
2. **次新股会破坏口径**：2024 年后上市、月度数据不足 30 个月的股票（长鑫科技、华电新能等）已剔除，否则图表会缺月、年化收益失真。
3. **松发股份（603268）是特殊样本**：2024 年重大资产重组，主业由陶瓷转向船舶制造，`+892.7%` 主要反映重组预期，不是军工内生增长。任何对外结论都要带这句注脚。
4. **停牌/退市**：baostock 对停牌日不返回数据；若某股长期停牌，月度序列会缺月，前端表现为断点（`connectNulls: true`）。
5. **时间与时区**：15:05 前不把当天算作已收盘，否则会把盘中不完整数据写进库。
6. **baostock 会断连**：socket 偶发 `10054`。服务端已有 3 次重试 + 重新登录；批量抓取建议串行 + 小延迟，不要高并发。
7. **pypi/files.pythonhosted 在本机很慢**：依赖已 vendor 到 `backend/vendor`，重装请用 `vendor_backend2.py`（走清华镜像），不要直接 `pip install`（会卡住且受临时目录权限限制）。
8. **npm/esbuild 在沙箱里会 `spawn EPERM`**：构建前端需要子进程权限；`start.ps1` 在普通终端运行正常。
9. **端口 3999**：被占用时 `start.ps1` 会直接报错；可用 `ASTOCK_PORT` 覆盖。
10. **`/api/sync` 的任务状态在内存里**：服务重启后历史 job 丢失（数据库里仍有 `sync_log`）。

## 9. 维护者须知（改口径时的连锁反应）

改动以下任何一项，必须同步修改**三处**：`backend/app/config.py`、`seed.py` 的导入逻辑、本文件的「数据口径」表，并重跑 `python -m app.seed`。

1. 归一化基期（`BASE_MONTH`）
2. 龙头数量（当前固定 5）
3. 次新股排除规则（当前 < 30 个月）
4. 复权方式（当前前复权）
5. 行业分类版本（当前申万 2021 版）

前端无需改代码，但 `docs/00` 与 `docs/03` 需要更新。
