## 3. 技术债清单

| # | 债务 | 影响 | 建议处理 | 优先级 |
|---|---|---|---|---|
| 1 | 同步任务状态存在进程内存 `_JOBS` | 重启丢任务；多进程不可用 | 落库 `sync_job` 表 | P0 |
| 2 | 同步串行、单只约 2s | 156 只约 5 分钟 | 连接复用 + 受控并发 + 窗口合并 | P0 |
| 3 | 残留 `running` 日志 | 审计数据失真 | ✅ 2026-11-17 已实现启动自动标记 | — |
| 4 | **无总超时/熔断/取消** | 上游异常时同步可挂 10+ 分钟 | 总超时 10min + 连续失败熔断 + 探活 + cancel 接口 | P0 |
| 5 | 无迁移工具（`create_all`） | 改字段需手工 DDL，易漂移 | 引入 Alembic | P1 |
| 6 | `/api/prices` 的 `normalize` 参数无效 | 文档与实现不一致 | 实现或删除 | P1 |
| 7 | admin token 明文、单一 | 本地够用，不适合多人 | `.env` + 启动校验；多人时上登录 | P2 |
| 8 | 无分页/限流 | 全市场扩展后可能拖慢 | 数据量小可延后；`/api/prices` 已有 60 只上限 | P2 |
| 9 | `price_daily` 混存月末行与逐日行 | 语义不纯（`source` 区分） | 长期统一为逐日；月末行仅作种子 | P2 |
| 10 | 前端单 bundle 1.19 MB | 首屏稍慢（本地无感） | ECharts 按需 + 代码分割 | P2 |
| 11 | 无 CI / 无 lint | 回归靠人工 | `ruff` + `eslint` + Actions（若上云） | P2 |
| 12 | `vendor/` 体积大（63 MB） | 仓库偏大 | `requirements.txt` + 内网源，或 Git LFS | P3 |
| 13 | SQLite 未开 WAL | 并发写可能锁库 | 连接事件里 `PRAGMA journal_mode=WAL` | P2 |
| 14 | 时间判定用「工作日」近似交易日 | 节假日误判 `needsRefresh` | 接交易日历（baostock `query_trade_dates`） | P1 |
| 15 | 同步失败只保留最后一条 message | 无法定位多只失败 | 失败清单（JSON/列表）写入日志 | P0 |

## 4. 风险登记

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| baostock 接口变更/停服 | 中 | 同步失效 | 备选腾讯/新浪源（需重定复权口径）；保留 CSV 导入兜底 |
| 申万官网接口改版 | 低 | 无法自动更新权重 | 权重已落库；手工维护入口（P5） |
| 前复权口径变化导致历史漂移 | 中 | 图表新旧不一致 | 精确重叠校验 + 整只重建（已实现）；定期跑 quality |
| 同步误判重建（2026-11-16 已发生） | 中 | 行数暴涨、耗时变长 | 已修复比对逻辑；v0.2.3 增加耗时与 rebuilt 监控告警 |
| 端口/路径写死 | 低 | 换机启动失败 | 已参数化（`ASTOCK_*`） |
| 单机磁盘故障 | 低 | 数据丢失 | 定期复制 `astock.db`（见 05 §7） |
| 无鉴权被局域网访问 | 低 | 数据被读 | 只绑 127.0.0.1；如需局域网先加认证 |

## 5. 已知但暂不处理

- 移动端独立 App：当前响应式足够。
- 实时行情/分时：数据源与存储模型不同，属于另一个项目。
- 回测/选股：需要复权因子、财务数据、交易日历，超出本服务范围。
- 多用户并发编辑：本地单人使用，冲突概率为零。

## 6. 完成定义（DoD）

任何一项任务完成，需同时满足：

1. 代码可运行（`python run.py` + `npm run build` 均通过）。
2. 页面/接口人工验证过（附截图或 curl 输出）。
3. 相关文档更新（00/03/04/05/06 按影响面）。
4. **`10-当前状态.md` 已更新**（版本、行数、最新交易日、已知问题）。
5. **`11-路线图.md` 勾选对应项**，必要时调整下一版本。
6. `09-变更日志.md` 增加一条（日期、版本、改动、影响）。
7. 无新增 `sync_log` 失败记录；无 `running` 残留。
8. `python service/docs/_check_docs.py` 通过。
